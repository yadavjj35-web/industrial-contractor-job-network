# Industrial Contractor Job Network

Complete MERN-style backend + static frontend project.

## Setup
1. Open `backend`
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Add MongoDB connection and secrets
5. Run `npm run dev`
6. Open frontend with Live Server or deploy frontend separately.

Default API URL in frontend: `http://localhost:5000/api`
Change it in `frontend/js/config.js` after deployment.
